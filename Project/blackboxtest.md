# Signup Blackbox Defect Log

Project: V-SNKR Web Application  
Module: Signup / Account Activation / Related Login Feedback  
Test Basis: Requirement expectations derived from [MainFlow_Integration_System_TestCases.md](./MainFlow_Integration_System_TestCases.md) and observed system behavior from the current implementation  
Prepared Date: 23/04/2026

## Scope

This defect log focuses on blackbox defects identified around the signup flow, activation flow, and closely related login behavior for newly registered users. The listed issues were derived by comparing the expected outcomes in the requirement-based test cases with the externally observable behavior implied by the current system implementation.

- Screenshots, execution timestamps, environment IDs, and retest evidence can be added later during actual manual test execution.
- The list includes both functional and usability/security-oriented blackbox defects because those behaviors are also covered by the current requirement-based system test cases.
